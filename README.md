# MoniePoint Frontend

A collection of frontend projects and assignments for learning and development.

## Project Structure

```
moniepointFrontend/
├── weekThree/
│   ├── dayOne/
│   │   └── SlidingWindowAlgorithm.java
│   └── Frontend/
│       ├── index.html
│       ├── style.css
│       ├── assignment/
│       │   ├── index.html
│       │   └── style.css
│       └── figma/
│           ├── index.html
│           └── style.css
└── README.md
```

## Folders

### weekThree/dayOne
Contains algorithmic implementations:
- **SlidingWindowAlgorithm.java** - Java implementation of the sliding window algorithm

### weekThree/Frontend
Main frontend projects folder with three sub-directories:

#### assignment/
A responsive landing page for the "Biccas" productivity dashboard application. Features include:
- Modern navigation header with authentication buttons
- Hero section with call-to-action buttons
- Brand partnerships showcase
- Support and features sections
- Pricing plans grid
- Contact form with testimonials
- Responsive footer with links

**Files:**
- `index.html` - Landing page structure
- `style.css` - Styling with responsive design

#### figma/
Design reference and prototype files related to Figma designs.

**Files:**
- `index.html` - Figma design page
- `style.css` - Associated styling

#### Root Files
- `index.html` - Main frontend entry point
- `style.css` - Global styling

## Getting Started

1. Navigate to the desired project folder
2. Open the HTML files in a web browser
3. For the assignment, all styling is contained in `style.css`

## Features

- **Responsive Design** - Mobile-friendly layouts using CSS Grid and Flexbox
- **Modern Styling** - Clean, professional design with smooth interactions
- **Font Integration** - Uses Josefin Sans from Google Fonts
- **Color Scheme** - Consistent green accent color (#54bd95) with neutral grays

## Customization

### Font Sizes
Base font size is set to 18px. All other sizes scale from this value using rem units.

### Colors
- Primary: `#54bd95` (green)
- Dark: `#1f2937` (text)
- Muted: `#6b7280` (secondary text)
- Soft: `#f5f7fa` (light backgrounds)

### Layout
- Full-width container with 20px side padding
- Grid-based layout for sections
- Maximum content width follows responsive design patterns

## Notes

- All projects use vanilla HTML, CSS, and JavaScript
- No external frameworks or dependencies required
- Responsive design tested for desktop and mobile viewing
